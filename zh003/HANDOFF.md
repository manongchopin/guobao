# ZH-003 内容接入说明

> 这份文件是写给**接手做网站的那个 agent** 的。读完它，你应该能在不了解背景的情况下把这批内容正确地放上站点。

## 一、这是什么

一个人用卫星影像在境外找出的一批**中国式古城**：辽的镇州四城在蒙古国，渤海的盐州城在俄滨海，元的齐王王府在外贝加尔，汉的西域都护府在轮台。

共 **34 处**，其中 33 处有精确到秒的经纬度，每处配一张 600 米见方的卫星影像。

来源：知乎问题「你在谷歌地球（Google Earth）有什么独特的发现？」答主 **木人口**。
原文链接：<https://www.zhihu.com/question/56763164/answer/586721566>

**这不是一份正式的考古名录**，是一个人的个人观察，其中有 6 处作者自己就存疑。展示时不要拔高成学术结论。

## 三、数据字段

`sites.json` 顶层：

| 字段 | 说明 |
|---|---|
| `archive` | `"ZH-003"`，档案号 |
| `source` | 平台、问题、作者、原始 URL |
| `captured` | 抓取日期 `2026-11-01` |
| `image_credit` | 影像署名，**必须展示** |
| `image_note` | 影像取景说明（600 米见方、十字准星、100 米比例尺） |
| `caveats` | 四条必须让读者看到的免责说明 |
| `stats` | 总数、有坐标数、国家数、朝代分布 |
| `sites` | 34 条记录数组 |

每条 `sites[]`：

| 字段 | 类型 | 说明 |
|---|---|---|
| `no` | int | 编号 1–34，按原文出现顺序，**不要重排** |
| `name` | str | 原文名称，如「辽代西北路招讨司治所」 |
| `place` | str | 今地，如「俄罗斯·滨海边疆区」 |
| `country` | str | 现代国家，用于分组和筛选 |
| `era` | str | 朝代/时期：辽、元、渤海、汉、唐、清、西辽…… |
| `kind` | str | 城址 / 山城 / 障城 / 边墙 / 墓葬 |
| `stance` | str | **作者态度**：`直陈` 或 `存疑` |
| `lat` / `lon` | float | 十进制经纬度，可直接给地图库 |
| `lat_dms` / `lon_dms` | str | 原文度分秒，展示用 |
| `quote` | str | 作者原话，**照录，不要改写** |
| `editor` | str | **编者注**，本项目加的判断，可能为空字符串 |
| `image` | str | `cards/01.jpg` 之类；第 31 条为 `null` |

## 四、页面上至少要有的东西

1. **列表 / 卡片流**：34 条，每条显示编号、名称、今地、朝代、缩略图。第 31 条没有图，用占位块。
2. **详情**：大图 + 名称 + 今地 + 朝代·类型 + 作者原话 + 坐标（DMS 与十进制都给）。
3. **筛选**：至少能按 **朝代** 和 **现代国家** 筛；作者态度（直陈/存疑）能筛更好。
4. **数据来源与免责**：来源 URL、抓取日期、`caveats` 四条、影像署名。

地图页可选。若做，用 `lat`/`lon` 直接打点即可，颜色建议按朝代分组。

## 五、硬约束（这几条不能改）

1. **影像必须署名**：`Esri / Maxar / Earthstar Geographics`。这是有版权的商业影像，个人研究可，对外发布要带上署名。
2. **编者注必须与作者口径分开**。`quote` 是作者说的，`editor` 是我们加的。不要把两者混成一段话，也不要把编者注写成正文。
3. **`stance` 只能有两种**：`直陈` / `存疑`。存疑的 6 处是第 8、10、22、24、26、34 条——作者原话里就有「疑」「怀疑」「或为」「似乎」「不知」。**不要替作者升级或降级**。
4. **第 31 条（阿富汗青铜时代王陵封土群）没有坐标也没有影像**，原文只写了「阿富汗境内某地」。只能列表展示，不要给它编一个位置。
5. **编号不要重排**。`no` 是原文顺序，改了就回不到原文对照。
