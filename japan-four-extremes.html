JAPAN · FOUR EXTREMES

日本四极

不是四个点，是四套坐标。
国家尺度、本土四极、四岛各自、证书四极，分开看才不会混。

极

“日本最北端”这句话，至少有三层意思：日本主张的领土、日本实际管辖的极点、普通人买票能到的极点。再往下，还有“本土四极”和“北海道/本州/四国/九州各自四极”。这个页面把这几套坐标放在同一张地图上，用模式切换。

证书要分清：宗谷岬、納沙布岬、佐多岬、神崎鼻四张“日本本土四極踏破証明書”拼成一张，对应的是本土四极；它不包括南鸟岛、冲之鸟岛、波照间岛或与那国岛这些国家尺度的极点。

CERTIFICATES · 04

四张证书怎么拿

四张证书拼成一张“日本本土四极踏破证明书”。以下窗口、时间和费用按公开信息整理；出发前请再确认，尤其是冬季和离岛交通。

怎么排线：不要把它当一条直线

四个点分在北海道和九州，最现实的是拆成两段，而不是一次从北到南硬串。证书线按“北 → 东 → 南 → 西”只是顺序，不是地理直线。

A · 北海道段

稚内 → 宗谷岬 → 根室 → 納沙布岬

2–3 天。稚内进出，先拿最北；再飞/转往根室拿最东。冬季巴士和航班都要留余量。

B · 九州段

鹿児島 → 佐多岬 → 佐世保 → 神崎鼻

2–3 天。先到本土最南，再转佐世保拿最西；神崎鼻公交少，建议自驾或出租车。

C · 一次走完

四个航班，7–9 天

东京 → 稚内 → 根室 → 鹿児島 → 长崎/佐世保。不是不能一次走完，但会把时间花在转场上。

已到访标记：右侧每条有“标记到访”，只存在本机浏览器，不会上传。证书点的进度单独算 0 / 4。

ITINERARY · TWO BLOCKS

两段日程骨架

不是“四极一条线”，而是北海道、九州各一段。时间是骨架，班次和季节一变就要重排；所有“约”都要在出发前复核。

A

北海道段 · 3 天 2 晚

稚内进，根室出；最北 + 最东。

  1. DAY 1

    东京 → 稚内 → 宗谷岬

    羽田飞稚内，机场巴士进市区，站前换宗谷巴士去宗谷岬。看最北端碑，现场买“最北端到達証明書”，回稚内住。

    宿：稚内。若航班到得晚，把宗谷岬挪到第二天早上。
  2. DAY 2

    稚内 → 新千岁 → 中标津 → 根室

    稚内飞新千岁，转中标津；机场巴士到根室。这一天主要在路上，晚上只安排市区和吃饭。

    宿：根室。不要安排“当天再去纳沙布岬”，容易赶不上末班。
  3. DAY 3

    根室 → 納沙布岬 → 根室 → 东京

    早上根室站前坐纳沙布线去岬角，看最东端碑；证书可在根室市役所、观光协会或北方领土资料馆拿。回根室后去机场。

    3 天版偏紧；想留天气和航班缓冲，改 4 天 3 晚。
B

九州段 · 3 天 2 晚

鹿儿岛进，佐世保/长崎出；最南 + 最西。

  1. DAY 1

    东京 → 鹿儿岛 → 根占 / 南大隅

    羽田飞鹿儿岛，机场巴士到鹿儿岛中央，再南下根占。住南大隅一带，第二天一早去佐多岬。

    宿：根占或南大隅。公交班次少，先查好末班。
  2. DAY 2

    佐多岬 → 鹿儿岛 → 佐世保

    早上去佐多岬，拿“日本本土最南端証明書”；回根占、鹿儿岛中央，转新干线+特急去佐世保。

    宿：佐世保。这一天移动很长，别再加景点。
  3. DAY 3

    佐世保 → 小佐々 → 神崎鼻 → 长崎 / 东京

    佐世保站前坐巴士到小佐々，再出租车去神崎鼻；到最西端碑和证书窗口。回佐世保或直接去长崎机场。

    神崎鼻公交很疏，建议自驾或让出租车等；3 天版适合只跑证书。

怎么读这张图

  • 国家尺度：択捉島カモイワッカ岬（主张）、弁天島（实控极北）、南鳥島（最东）、沖ノ鳥島（最南）、Tuishi（最西），以及普通人可到的宗谷岬、納沙布岬、波照間島高那崎、与那国島西崎。
  • 本土四极：宗谷岬、納沙布岬、佐多岬、神崎鼻；这是四座主岛整体的四极，不含离岛。
  • 四岛各自：北海道、本州、四国、九州各四个端点，共 16 个；同一个宗谷岬会同时出现在“本土”和“北海道”里，但含义不同。
  • 坐标：部分为近似值，地图只作方位示意；实际到访请以当地道路、航线和设施公告为准。
