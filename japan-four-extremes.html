日本四极

不是四个点，是四套坐标。
国家尺度、本土四极、四岛各自、证书四极，分开看才不会混。

极

“日本最北端”这句话，至少有三层意思：日本主张的领土、日本实际管辖的极点、普通人买票能到的极点。再往下，还有“本土四极”和“北海道/本州/四国/九州各自四极”。这个页面把这几套坐标放在同一张地图上，用模式切换。

CERTIFICATES · 04

四张证书怎么拿

四张证书拼成一张“日本本土四极踏破证明书”。以下窗口、时间和费用按公开信息整理；出发前请再确认，尤其是冬季和离岛交通。

怎么排线：不要把它当一条直线

四个点分在北海道和九州，最现实的是拆成两段，而不是一次从北到南硬串。证书线按“北 → 东 → 南 → 西”只是顺序，不是地理直线。

A · 北海道段

稚内 → 宗谷岬 → 根室 → 納沙布岬

2–3 天。稚内进出，先拿最北；再飞/转往根室拿最东。冬季巴士和航班都要留余量。

B · 九州段

鹿児島 → 佐多岬 → 佐世保 → 神崎鼻

2–3 天。先到本土最南，再转佐世保拿最西；神崎鼻公交少，建议自驾或出租车。

C · 一次走完

四个航班，7–9 天

东京 → 稚内 → 根室 → 鹿児島 → 长崎/佐世保。不是不能一次走完，但会把时间花在转场上。

已到访标记：右侧每条有“标记到访”，只存在本机浏览器，不会上传。证书点的进度单独算 0 / 4。

怎么读这张图

  • 国家尺度：択捉島カモイワッカ岬（主张）、弁天島（实控极北）、南鳥島（最东）、沖ノ鳥島（最南）、Tuishi（最西），以及普通人可到的宗谷岬、納沙布岬、波照間島高那崎、与那国島西崎。
  • 本土四极：宗谷岬、納沙布岬、佐多岬、神崎鼻；这是四座主岛整体的四极，不含离岛。
  • 四岛各自：北海道、本州、四国、九州各四个端点，共 16 个；同一个宗谷岬会同时出现在“本土”和“北海道”里，但含义不同。
  • 坐标：部分为近似值，地图只作方位示意；实际到访请以当地道路、航线和设施公告为准。
